# カスタムマップ削除と有限補給（v0.9.3）

## カスタムマップの削除

タイトルのカスタム作戦カードにある「マップを削除」から操作します。組み込み作戦には表示しません。名前を示す確認で中止でき、保存に失敗した場合は一覧から除去せずエラーを表示します。エディタの削除も同じ処理を使います。

一覧からの削除後も、進行中の対局、手動・自動・名前付き保存、リプレイは保持します。現在の対局へ戻ることや、定義を同梱した保存・リプレイの読み込みができます。カタログからの削除に取り消し操作はありません。再利用するマップは先にJSONへ書き出してください。旧対局の再現に必要な定義の履歴は残ることがあり、削除は全保存領域の即時解放を保証しません。

## 補給方式

新規対局のルールv10では、装甲兵員輸送車（APC）が物資を持ちます。キャンペーン以外の作戦準備では「有限」と従来の「無制限（v9）」を選べます。CPU観戦・2人対戦も同様です。キャンペーンの新しい出撃は有限です。保存済みの対局は記録されたルールを維持します。

| 項目 | 有限補給の規則 |
| --- | --- |
| 初期・生産時の物資 | APC1両につき300ポイント |
| 消費 | 弾薬1発10ポイント、燃料1につき1ポイント |
| 対象 | 隣接する自軍地上部隊と、自車の搭載部隊 |
| 実施時点 | 自軍手番開始時。移動した直後には補給しない |
| 残量不足 | 支払える分だけ補給し、0で停止 |
| 物資の補充 | APCが自軍都市・工場・司令部上、または自軍前線補給所の上・隣接1マスにいる手番開始時に300へ戻す |
| 対象外 | 敵、航空機・艦船、HP回復、APC間の物資移送 |

固定施設と前線補給所の補給を先に適用し、その後APCから配ります。固定補給自体に有限在庫は設けません。搭載部隊を優先し、残りの受給部隊と供給車はそれぞれIDの昇順で決定します。同一部隊には主武器、第二武器、燃料の順です。複数APCがいても同じ回復を二重請求しません。施設上で補充したAPCも、その手番に配った物資は消費します。

APCは自分自身へ配れません。自分の弾薬・燃料は固定補給か隣接APCで回復しますが、物資は固定補給だけで補充できます。補給車と補給所にHP修理はなく、対応施設での従来の有料修理は維持します。

## CPUと表示

- APCの物資が100以下になると、CPUは物資を補充できる自軍施設・補給所へ向かう判断を行います。常に帰投を保証する規則ではなく、目標・輸送・交戦判断と競合します。
- 空のAPCを前線の補給源として評価せず、所持物資で実際に回復できるかを判定します。低残量では新しい輸送乗員の積載を避け、既存の搭載任務は継続できます。
- 自軍APCの残量はマップ近くのユニット情報とマス情報に表示します。敵の残量は非公開です。観戦の全体視点では各軍の情報を確認できます。
- 空のAPCは補給範囲から除きます。残量のあるAPCも全回復を保証せず、他部隊への配分や残量による部分補給を案内します。
- ルールv9以前のセーブ・リプレイは無制限のまま動作します。対局の途中で補給方式は変更しません。戦績はルール版ごとに分かれます。

## 保存と検証

セーブ・リプレイ・キャンペーン進行のschema v4は維持し、新ルールv10とAPCの任意フィールド`supplyStock`（整数0〜300、未指定は満載）を検証します。APC以外や旧ルールに残量を付けた入力は拒否します。保存された現在値はコマンド再現とも照合します。v0.9.2以前のアプリはルールv10を読めません。

検証範囲と比較結果は[評価記録](reviews/2026-10-23-finite-supply.md)、公開内容は[v0.9.3リリースノート](releases/v0.9.3.md)を参照してください。
