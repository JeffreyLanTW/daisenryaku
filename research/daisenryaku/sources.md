# 其他來源

## GitHub

### [hguyswow/Advanced_Daisenryaku_ko](https://github.com/hguyswow/Advanced_Daisenryaku_ko)
MD『アドバンスド大戦略 ドイツ電撃作戦』（1991，SystemSoft）韓文化 IPS 補丁 v0.11（未完成）。只有二進位補丁與截圖，**沒有可擷取的兵種或地圖資料**。README 透露的規模：
- STANDARD 劇本 44 個，作戰簡報 43 段、戰況敘述 93 段
- 兵器 690 種、武裝 159 種
- 原版 ROM 1 MB（日版 Rev.A），補丁後 2 MB

### [kumakumapon/MiniStr](https://github.com/kumakumapon/MiniStr)（MIT）
TypeScript／Vite 的同人戰略遊戲，明確以ファミコンウォーズ／大戦略為參考。可參考的設計文件：
- `docs/reviews/2026-09-27-zoc-design.md`：大戰略式 ZOC（控制區）簡化設計，建議做成可選的「大戦略モード」
- `docs/campaign-operations.md`、`docs/reviews/2026-10-15-campaign-cpu.md`：參考大戦略VII EXCEED 的多戰場與經驗繼承、大東亜興亡史的出擊前整備
- `docs/frontline-logistics.md`、`docs/finite-supplies.md`：補給車前線補給、有限補給
- `docs/river-crossing.md`、`docs/airlift.md`：渡河、空運

### [plastichyena/nowherelefttohide](https://github.com/plastichyena/nowherelefttohide)（PolyForm Noncommercial）
受大戰略系列影響的手機優先殭屍六角格戰略 PoC；`Doc/archive/` 有日文需求規格書。授權禁止商用，只供閱讀參考。
